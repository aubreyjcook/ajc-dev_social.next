# ajc-dev_social.next

A social networking website built with [Next.js](https://nextjs.org).

## Current version

The project is in **alpha / pre-release**. Each version lives in its own
directory named `v0_0x`.

| Version | Directory                | Status        |
| ------- | ------------------------ | ------------- |
| v0.01   | [`v0_01/`](v0_01/)       | Groundwork    |

## Getting started

See the current version's README for setup and usage instructions:

- [`v0_01/ajc-social-next-av0-01/README.md`](v0_01/ajc-social-next-av0-01/README.md)

## Repository conventions

- Versions are kept in `v0_0x` directories (`v0_01`, `v0_02`, ...).
- At most **three** version directories are kept side by side; the oldest is
  archived when a fourth is created.
- Every version includes documentation: how to use the software, how the code
  works (for learners), what changed, and a roadmap for the next version.
- Working instructions for the project as a whole live in
  [`agent-instructions.md`](agent-instructions.md).
